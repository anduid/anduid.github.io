Pertanyaan yang Sering Diajukan (FAQ)

Berapa lama rata-rata proses pembuatan aplikasi dari awal?

expand_more
Untuk prototype MVP (Minimum Viable Product), durasi pengerjaan rata-rata memakan waktu 4 hingga 8 minggu kerja terbagi dalam sprint dua mingguan. Sementara itu, untuk sistem web skala enterprise atau platform multi-role kompleks, pengerjaan berkisar antara 2 hingga 4 bulan dengan deliverable bertahap.

Apakah hak cipta dan seluruh source code menjadi milik klien 100%?

expand_more
Ya, 100%! Setelah pembayaran final milestone selesai, seluruh kekayaan intelektual (IP), source code repository di GitHub/GitLab, akun cloud infra, file master Figma UI/UX, dan kredensial database diserahkan penuh tanpa biaya lisensi tahunan tambahan dari kami.

Bagaimana jika aplikasi butuh penyesuaian atau ditemukan bug setelah peluncuran?

expand_more
Setiap proyek di andu.my.id otomatis dilindungi oleh Garansi Bebas Bug (Warranty SLA) selama 3 bulan pertama setelah rilis publik. Untuk ekspansi fitur lanjutan, Anda dapat beralih ke skema Tech Partner Retainer atau sprint add-on dengan estimasi biaya transparan.

Apakah andu.my.id membantu proses publishing ke Google Play Store dan Apple App Store?

expand_more
Tentu saja! Kami menangani seluruh checklist teknis publikasi: pembuatan build signing, assets screenshot marketing, compliance privacy policy, hingga mendampingi proses App Review oleh pihak Google dan Apple sampai aplikasi berhasil live dan dapat diunduh pengguna.
